Panda NFT adalah project latihan yang saya kerjakan untuk mengasah kemampuan membangun landing page bertema Web3/NFT dengan pendekatan UI yang lebih berani dan interaktif.

## Gambaran Proyek

Proyek ini berfokus pada pembuatan halaman promosi koleksi NFT bertema Panda, dengan tujuan utama:

- menampilkan identitas visual koleksi
- memperkenalkan utility dan roadmap singkat
- mendorong pengguna untuk eksplorasi koleksi

## Fitur Utama

### Hero Section Interaktif

- Headline utama dengan visual karakter Panda NFT.
- Call-to-action untuk melihat koleksi.
- Komposisi layout yang dibuat menonjol untuk first impression.

### Section Utility dan Roadmap

- Penjelasan manfaat kepemilikan NFT.
- Timeline roadmap project dalam format yang mudah dipahami.
- Struktur konten ringkas agar tetap fokus pada conversion.

### Desain Responsif

- Tampilan tetap optimal di desktop dan mobile.
- Spacing, tipografi, dan ukuran elemen disesuaikan per breakpoint.

## Implementasi Teknis

### Next.js App Router

Digunakan untuk struktur routing modern, modularitas komponen, dan performa rendering yang baik.

### Tailwind CSS

Mempercepat proses styling dengan utility classes dan menjaga konsistensi desain antar section.

### Framer Motion

Digunakan untuk animasi ringan seperti reveal section dan transisi elemen agar interaksi terasa lebih hidup.

## Tujuan Pembelajaran

Sebagai project latihan, fokus pembelajaran utamanya adalah:

- merancang landing page tematik yang kuat secara visual
- meningkatkan keterampilan layout responsif
- menerapkan animasi yang mendukung pengalaman pengguna
- menjaga struktur komponen tetap rapi dan reusable
