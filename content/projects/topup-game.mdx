TopUp Game Store adalah project frontend yang saya buat untuk mensimulasikan pengalaman pembelian top up game secara cepat, sederhana, dan responsif.

## Gambaran Proyek

Proyek ini berfokus pada antarmuka pengguna untuk kebutuhan top up game, mulai dari pemilihan game sampai ringkasan checkout.

Cakupan utama:

- tampilan katalog game populer
- pemilihan nominal top up
- pemilihan metode pembayaran
- ringkasan transaksi sebelum checkout

Karena ini project latihan frontend, seluruh data masih berupa mock data di sisi client.

## Fitur Utama

### 1. Katalog Game

- Menampilkan daftar game dalam bentuk card.
- Menyediakan visual cover game agar user cepat mengenali produk.
- Layout dirancang agar nyaman dibaca di desktop dan mobile.

### 2. Nominal Top Up

- User dapat memilih nominal sesuai kebutuhan.
- Opsi nominal ditampilkan dengan gaya tombol yang jelas dan mudah diinteraksikan.
- State pilihan langsung terlihat untuk meminimalkan kesalahan input.

### 3. Metode Pembayaran

- Menampilkan beberapa opsi pembayaran populer.
- Struktur UI memudahkan user membandingkan opsi yang tersedia.
- Alur pemilihan dibuat singkat agar proses lebih cepat.

### 4. Ringkasan Checkout

- Menampilkan detail game, nominal, metode pembayaran, dan total harga.
- Membantu user melakukan verifikasi akhir sebelum konfirmasi.

## Implementasi Teknis

### Next.js

Digunakan untuk membangun halaman frontend dengan struktur komponen yang rapi dan mudah dikembangkan.

### Tailwind CSS

Dipakai untuk styling cepat menggunakan utility classes, sekaligus menjaga konsistensi UI pada seluruh section.

## Catatan Pengembangan

Project ini murni **frontend only** dan belum terintegrasi ke backend/payment gateway. Tujuan utamanya adalah latihan membangun UI e-commerce sederhana dengan flow transaksi yang jelas.
