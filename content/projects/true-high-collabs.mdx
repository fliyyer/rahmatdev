True High Collabs adalah platform e-commerce kesehatan dan suplemen alami berbasis di Inggris yang memadukan produk herbal berkualitas tinggi dengan pengalaman belanja digital yang cepat, aman, dan modern.

## Gambaran Proyek

Proyek ini dibangun menggunakan arsitektur modern berbasis decoupled web application. Dengan memisahkan layer frontend dan backend, aplikasi mampu menyajikan performa loading yang sangat cepat, SEO optimal, serta skalabilitas manajemen produk yang andal.

Fokus utama proyek:

- Menyusun arsitektur e-commerce decoupled berbasis **Next.js** dan **NestJS**.
- Membangun antarmuka katalog produk kesehatan yang modern, responsif, dan interaktif.
- Mengelola API manajemen produk, inventaris, checkout, dan transaksi pada sisi backend.
- Menerapkan modul verifikasi umur (*Age Gate*) serta integrasi ulasan kepercayaan (Trustpilot).

## Fitur Utama

### 1. Modern E-Commerce Storefront
- Katalog produk dinamis dengan performa SSR/SSG tinggi dari Next.js.
- Alur keranjang belanja (*shopping cart*) dan checkout instan yang mulus.

### 2. High-Performance REST API
- Backend API scalable yang dibangun menggunakan NestJS dengan TypeScript untuk menangani logika transaksi, inventaris, dan otentikasi.

### 3. Age Gate Verification
- Modul verifikasi usia legal berbasis modal interaktif untuk memastikan kepatuhan regulasi produk kesehatan.

### 4. Layout Responsif & Fast Loading
- Antarmuka ultra-responsif dengan Tailwind CSS yang nyaman diakses dari berbagai ukuran perangkat.

## Implementasi Teknis

### Frontend Stack
- **Next.js**: Framework React untuk rendering antarmuka cepat dengan optimasi gambar dan SEO kelas dunia.
- **TypeScript & Tailwind CSS**: Menjaga Type Safety pada komponen UI dan styling utility-first yang rapi.

### Backend Stack
- **NestJS**: Framework Node.js progresif berorientasi modul untuk membangun backend REST API yang terstruktur dan scalable.

## Hasil

Pengembangan ulang True High Collabs dengan stack **Next.js + NestJS** menghasilkan aplikasi e-commerce yang jauh lebih cepat, modern, dan scalable untuk mendukung pertumbuhan bisnis dalam jangka panjang.
