Equinox adalah proyek **full stack** yang saya kerjakan end-to-end untuk kebutuhan **booking online self studio**, mulai dari pengalaman pengguna di frontend sampai pengelolaan reservasi dan pembayaran di backend.

## Gambaran Proyek

Proyek ini dibangun untuk mempermudah pelanggan melakukan pemesanan sesi studio secara online, memilih jadwal, melakukan pembayaran, dan mendapatkan konfirmasi booking dengan alur yang jelas.

Peran saya pada proyek ini:

- Membangun frontend React berbasis komponen
- Mendesain UI dengan pendekatan **neo brutalism**
- Mengembangkan backend API menggunakan Laravel
- Mengintegrasikan alur pembayaran melalui **Pakasir Payment Gateway**
- Menyusun flow booking dari pilih slot hingga pembayaran sukses

## Fitur Utama

### 1. Frontend Neo Brutalism

- Visual tegas dengan kontras tinggi, border kuat, dan layout ekspresif.
- Kombinasi Tailwind CSS dan Ant Design untuk menjaga balance antara custom design dan komponen siap pakai.
- Komponen UI reusable untuk mempercepat pengembangan fitur.

### 2. Booking Slot Studio

- Pengguna dapat memilih tanggal dan jam sesi studio yang tersedia.
- Slot yang sudah terisi ditandai agar tidak terjadi double booking.
- Informasi durasi, harga, dan detail studio ditampilkan secara jelas.

### 3. Form Reservasi dan Checkout

- User mengisi data booking sebelum pembayaran.
- Ringkasan reservasi ditampilkan untuk verifikasi akhir.
- Validasi input diterapkan agar data reservasi tetap akurat.

### 4. Integrasi Payment Gateway Pakasir

- Sistem membuat transaksi pembayaran untuk booking studio.
- Status pembayaran digunakan untuk mengonfirmasi reservasi secara otomatis.
- User mendapat feedback status pembayaran dengan jelas.

### 5. Backend Laravel

- Laravel digunakan untuk API booking, manajemen jadwal, data user, dan transaksi pembayaran.
- Struktur backend dipisahkan per domain fitur agar maintainable dan mudah dikembangkan.

## Implementasi Teknis

### Frontend Stack

- **React JS** untuk membangun UI modular berbasis komponen.
- **Tailwind CSS** untuk custom styling cepat dan konsisten.
- **Ant Design (Antd)** untuk komponen produktif seperti form, date picker, modal, dan feedback state.

### Backend Stack

- **Laravel** untuk REST API, business logic booking, dan manajemen data reservasi.
- Integrasi **Pakasir Payment Gateway** untuk pembuatan invoice dan sinkronisasi status pembayaran.

## Tantangan dan Solusi

- Menjaga konsistensi tema neo brutalism sambil tetap nyaman dipakai pada flow booking.
- Menyusun mekanisme validasi slot agar meminimalkan benturan jadwal.
- Menjaga sinkronisasi status antara reservasi, pembayaran, dan konfirmasi akhir.

## Hasil

Proyek ini menghasilkan platform booking online self studio dengan alur reservasi yang jelas, proses pembayaran yang terintegrasi, dan fondasi backend yang siap dikembangkan. Sebagai full stack developer pada proyek ini, saya mengerjakan keseluruhan lifecycle dari UI hingga integrasi pembayaran.
