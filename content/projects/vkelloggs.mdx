VKelloggs adalah project website statis yang saya buat untuk melatih fondasi frontend menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Gambaran Proyek

Project ini berfokus pada pembuatan landing website produk dengan struktur konten yang jelas, visual yang menarik, dan interaksi dasar di sisi client.

Tujuan utama:

- memperkuat pemahaman semantic HTML
- membangun layout responsif menggunakan CSS
- menerapkan interaksi sederhana dengan JavaScript

## Fitur Utama

### 1. Hero Section Produk

- Menampilkan headline utama dan visual produk.
- CTA untuk mengarahkan pengunjung ke section berikutnya.
- Komposisi layout dibuat untuk menarik perhatian sejak awal.

### 2. Section Informasi Produk

- Menjelaskan manfaat dan keunggulan produk.
- Struktur konten dibuat ringkas agar mudah dibaca.
- Mendukung kebutuhan promosi produk secara cepat.

### 3. Interaksi Dasar JavaScript

- Efek interaksi ringan seperti toggle/menu atau animasi sederhana.
- Membuat halaman terasa lebih hidup tanpa library tambahan.

### 4. Responsif Multi-Device

- Layout menyesuaikan desktop, tablet, dan mobile.
- Pengaturan spacing dan tipografi dibuat tetap nyaman dibaca.

## Implementasi Teknis

### HTML

Digunakan untuk membangun struktur dokumen yang rapi dan semantik, sehingga konten mudah dipahami browser maupun pengguna.

### CSS

Digunakan untuk styling visual, layouting, dan media query agar tampilan konsisten serta responsif pada berbagai ukuran layar.

### JavaScript

Digunakan untuk interaksi sisi client agar pengalaman pengguna lebih interaktif tanpa kompleksitas framework.

## Catatan

Project ini murni project latihan fundamental frontend, sehingga sangat membantu untuk memperkuat dasar sebelum masuk ke ekosistem framework modern.
