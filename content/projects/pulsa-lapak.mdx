Pulsa Lapak adalah project web app frontend untuk kebutuhan pembelian pulsa dan paket data dengan pengalaman pengguna yang diprioritaskan untuk perangkat mobile.

## Gambaran Proyek

Project ini dirancang untuk mensimulasikan alur transaksi digital yang sederhana: pilih produk, isi nomor tujuan, cek ringkasan, lalu konfirmasi.

Fokus utama:

- mobile-first layout untuk penggunaan satu tangan
- alur pembelian yang singkat dan minim langkah
- tampilan informasi harga dan nominal yang jelas

## Fitur Utama

### 1. Mobile-First Interface

- Layout dimulai dari breakpoint mobile sebagai prioritas utama.
- Komponen penting (nominal, harga, tombol aksi) diletakkan di area mudah dijangkau.
- Tipografi dan spacing diatur agar tetap terbaca pada layar kecil.

### 2. Pilihan Produk Digital

- Menampilkan daftar produk seperti pulsa dan paket data.
- Opsi nominal disusun dalam bentuk kartu agar cepat dipilih.
- State aktif pada pilihan user ditampilkan dengan jelas.

### 3. Form Input Tujuan

- Input nomor tujuan dengan validasi dasar di sisi frontend.
- Feedback visual untuk membantu pengguna menghindari kesalahan input.

### 4. Ringkasan Transaksi

- Menampilkan detail produk, nominal, dan total harga.
- Membantu pengguna melakukan pengecekan sebelum konfirmasi.

## Implementasi Teknis

### React JS Web Apps

Digunakan untuk membangun antarmuka berbasis komponen yang reusable, sehingga tiap bagian flow transaksi bisa dikelola dan dikembangkan dengan lebih rapi.

### Tailwind CSS

Digunakan untuk styling cepat dengan utility classes, serta menjaga konsistensi tampilan mobile-first di seluruh halaman.

## Catatan Pengembangan

Project ini fokus pada sisi **frontend** untuk eksplorasi UX transaksi digital di perangkat mobile. Data produk dan transaksi masih berupa mock data untuk kebutuhan latihan.
