ML Strength adalah project website statis bertema kebugaran yang saya buat untuk melatih dasar pengembangan frontend tanpa framework.

## Gambaran Proyek

Project ini berfokus pada pembuatan landing website fitness dengan struktur konten yang jelas, visual yang kuat, dan interaksi sederhana agar pengalaman pengguna tetap menarik.

Tujuan project:

- mengasah struktur semantic HTML
- membangun layout responsif menggunakan CSS
- menambahkan interaksi ringan dengan JavaScript

## Fitur Utama

### 1. Hero Section Fitness

- Menampilkan headline motivasi dan visual utama.
- CTA untuk mengarahkan user ke section program latihan.
- Komposisi layout dibuat menonjol untuk first impression.

### 2. Section Program Latihan

- Menampilkan beberapa pilihan program/workout.
- Informasi disusun ringkas agar mudah dipahami pengunjung.
- Visual card membantu pemindaian konten lebih cepat.

### 3. Section Benefit dan Informasi

- Menjelaskan manfaat latihan dan value utama platform.
- Menjaga alur konten tetap terstruktur dari atas ke bawah.

### 4. Interaksi JavaScript Dasar

- Menambahkan interaksi sederhana seperti toggle/menu atau efek scroll ringan.
- Membuat website lebih hidup tanpa ketergantungan library tambahan.

## Implementasi Teknis

### HTML

Digunakan untuk struktur halaman yang semantik dan mudah dirawat.

### CSS

Digunakan untuk styling, layout, dan media query agar website tetap responsif di berbagai ukuran layar.

### JavaScript

Digunakan untuk menambah perilaku interaktif pada elemen UI agar pengalaman pengguna lebih baik.

## Catatan

Project ini adalah latihan fundamental frontend yang membantu memperkuat dasar sebelum membangun aplikasi dengan stack yang lebih kompleks.
